Subscribe, don't download

The buttons add a subscription, so changes reach your calendar on their own. A downloaded file is a one-off copy that never updates.

Doing it by hand

  • Google: Other calendars → + → From URL, and paste the link.
  • iPhone: Settings → Apps → Calendar → Calendar Accounts → Add Account → Other → Add Subscribed Calendar.
  • Outlook: Add calendar → Subscribe from web.

How fresh is it?

Calendars are rebuilt every 6 hours. Each app checks on its own schedule: Apple lets you choose, Google can take up to a day.
